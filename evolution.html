Engineering evolution

I didn't collect technologies. I kept moving toward harder problems.

Fourteen milestones across four eras. Each step was less about a new language and more about a harder class of problem than the one before it.

  • 14Milestones
  • 4Eras
  • 2016Started
  • 49Capabilities

Era 01

BUILD

2016 - 2019

Consumer to enterprise to architecture.

Learning to ship, then learning that shipping is the easy part. Four years moving from single features to systems somebody else could maintain.

4 milestones

  1. 2016 Building products people use

    Consumer Mobile

    Started with consumer mobile applications, developing strong foundations in mobile engineering, UX, performance, and product-focused development.

    • iOS
    • Swift
    • UIKit
    • Mobile UX
    • REST APIs
    • App Performance
  2. 2017 From screens to experiences

    Product Engineering

    Expanded from individual features into complete product experiences: navigation, networking, persistence, analytics, integrations, and release workflows.

    • Architecture
    • Networking
    • Persistence
    • API Integration
    • App Lifecycle
  3. 2018 Engineering through complexity

    Enterprise Mobile

    Moved into enterprise environments where workflows became deeper, systems became interconnected, and reliability mattered as much as the interface.

    • Enterprise Apps
    • Complex Workflows
    • Authentication
    • Integrations
    • Modular Architecture
  4. 2019 Designing beyond the feature

    Scalable Architecture

    Shifted from implementing features to designing reusable systems and application architectures that could survive being handed to somebody else.

    • Clean Architecture
    • MVVM
    • SOLID
    • Design Patterns
    • Modularisation
    • Reusable Components

Era 02

SCALE

2020 - 2021

Resilience first, then the whole platform.

Two years where the assumptions stopped holding. First connectivity, then the boundary between the app and everything behind it.

2 milestones

  1. 2020 Software for real conditions

    Field & Offline Systems

    Built systems that had to work beyond perfect connectivity, handling offline workflows, local persistence, synchronisation, retries, and real operational constraints.

    • Offline-First
    • Sync Engines
    • Local Databases
    • Background Processing
    • Resilience
  2. 2021 Mobile became part of the platform

    Full-System Thinking

    Expanded into backend services, APIs, databases, cloud workflows, and system-level architecture, connecting mobile experiences to platforms that could scale.

    • Python
    • FastAPI
    • PostgreSQL
    • REST APIs
    • Cloud Services
    • System Architecture

Era 03

INTELLIGENCE

2022 - 2023

The physical world, then the edge.

Software started reading the room, literally. Depth, vision and models moved onto the device, and performance stopped being a nice-to-have.

3 milestones

  1. 2022 Digital meets physical

    Spatial Computing

    Moved into spatial experiences using ARKit, LiDAR, computer vision, 3D environments, and sensor-driven interaction.

    • ARKit
    • LiDAR
    • 3D
    • Vision
    • Computer Vision
    • Spatial UX
  2. 2023 Bringing intelligence to the edge

    On-Device Intelligence

    Integrated machine learning directly into applications, working with local inference, computer vision, and intelligent behaviour that does not depend entirely on the cloud.

    • Core ML
    • Vision
    • On-Device ML
    • Model Integration
    • Edge Intelligence
  3. 2023 Making complex systems feel simple

    High-Performance Systems

    Deepened focus on performance: memory, rendering, data access, pagination, concurrency, synchronisation, and interfaces that stay responsive under load.

    • Swift Concurrency
    • Performance Engineering
    • Memory Optimisation
    • Pagination
    • Reactive Systems

Era 04

ACT

2024 - today

From responding to deciding, then leading.

Systems that answer in real time, then systems that decide and act. And the part that is not code at all.

5 milestones

  1. 2024 Systems that respond instantly

    Real-Time Systems

    Expanded into real-time communication and event-driven experiences, connecting live data, voice, streaming, and sockets to interactive behaviour.

    • WebSockets
    • Realtime Communication
    • Streaming
    • Voice
    • Event-Driven Systems
  2. 2024 From answers to actions

    Agentic AI

    Moved beyond conversational AI toward systems that understand context, coordinate tools, reason through a workflow, and carry out the result.

    • LLMs
    • AI Agents
    • Tool Calling
    • Context Engineering
    • AI Workflows
    • Voice AI
  3. 2025 AI as architecture, not a feature

    AI-Native Engineering

    Began treating AI as an architectural capability rather than an isolated feature, combining intelligent interfaces, automation, agents, data, and ordinary software engineering.

    • AI-Native Architecture
    • Agent Systems
    • AI UX
    • Automation
    • Intelligent Platforms
  4. Today Designing the whole system

    Solution Architecture

    Working across product, mobile, backend, AI, infrastructure, performance, and developer experience, turning complex requirements into systems that scale.

    • Solution Architecture
    • System Design
    • Cloud
    • Mobile
    • AI
    • Security
    • Scalability
  5. Today Multiplying engineering impact

    Technical Leadership

    Beyond writing code: technical direction, architecture decisions, engineering standards, mentoring, design systems, quality, and long-term maintainability.

    • Technical Leadership
    • Mentoring
    • Architecture Reviews
    • Engineering Standards
    • Design Systems
    • Delivery
